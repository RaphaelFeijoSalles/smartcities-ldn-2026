**Discussão de hoje:** cada integrante escolhe até 2 dores, pergunta ao mentor o sistema atual e a lacuna, define um usuário e uma demo de **2 minutos**; Miguel busca comprador/operador e evidência de adoção; Raphael verifica disponibilidade de dados/arquitetura; a equipe decide **uma ideia + uma reserva**.

**Regra P0:** 3–10 registros sintéticos/autorizados → ação concreta → resultado verificável → fonte e responsabilidade. Não implementar sem escolher. Pitch divulgado pelo evento: **3 minutos de fala + 2 minutos de demo**; confirmar retificações e regulamento integral.
